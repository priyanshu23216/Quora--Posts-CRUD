<h1 align="center">Quora Posts</h1>

<p align="center">
  A Quora-inspired web application built using Node.js, Express.js, and EJS.
</p>

<hr>

<h2>Features</h2>

<ul>
  <li>Create new posts</li>
  <li>View all posts</li>
  <li>Edit existing posts</li>
  <li>Delete posts using unique IDs</li>
  <li>Dynamic page rendering with EJS</li>
</ul>

<hr>

<h2>Tech Stack</h2>

<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript</li>
  <li>Node.js</li>
  <li>Express.js</li>
  <li>EJS</li>
</ul>

<hr>

<h2>Key Learnings</h2>

<ul>
  <li>CRUD operations</li>
  <li>RESTful routing and HTTP methods</li>
  <li>Express middleware</li>
  <li>Form handling and request bodies</li>
  <li>Dynamic rendering with EJS</li>
  <li>Unique ID generation using UUID</li>
</ul>

<hr>

<h2>Note</h2>

<p>
  This project uses an in-memory array for data storage.
  Data resets whenever the server restarts.
</p>
